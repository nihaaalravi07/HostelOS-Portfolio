# Academic evaluation material

HostelOS was developed as a software engineering and object-oriented design project at IIIT Allahabad. This folder holds the documents produced for the evaluation. They describe the project; the code in `backend/` and `frontend/` is the source of truth.

Some documents were generated from the source with scripts and verified against it; the documents carry their own statements of what is partial, missing or unverified. Cover pages contain the names and enrolment numbers of the project group. **Review that personal information before making the repository public.** The course lecture slides and laboratory manuals are not included, and the reference lists ask the team to add the exact titles.

## Software Engineering (`SE/`)

| File | Contents |
|---|---|
| `HostelOS_SE_Project_Report.docx` | Full SE project report |
| `HostelOS_SRS.docx` | Software requirements specification |
| `HostelOS_Architecture_Documentation.docx` | Architecture documentation |
| `HostelOS_Testing_Documentation.xlsx` | Test plan, cases and results |
| `HostelOS_Risk_Register.xlsx` | Risk register |
| `HostelOS_SE_Evaluation.pptx` | Evaluation presentation |
| `SE_SYLLABUS_MAPPING.md`, `DELIVERABLES_INDEX.md` | Mapping of the course syllabus to the documents |
| `diagrams/` | SDLC, use case, architecture, component, ER, sequence, activity, deployment, state and work-breakdown diagrams |
| `team-report-corrected/` | A corrected and a condensed version of the group's own report and presentation, with a `CORRECTIONS_LOG.md` listing every correction made against the code |
